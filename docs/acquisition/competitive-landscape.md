# Competitive Landscape — agentic compliance & payments (mid-2026)

> For diligence. Shows where Zawda sits and why "buy vs. build" favours the MENA layer. Player facts are from public sources (see end); verify before external citation.

## The five layers

**1. Payment rails / protocols (substrate — not Zawda's space).**
Coinbase **x402** (140M+ tx), Google + Coinbase **AP2** (Sept 2025), Mastercard Agent Pay, Visa Intelligent Commerce, MPP/ACP. Complementary plumbing.

**2. Agent wallets + spend-control / policy engines — COMMODITIZING.**
Coinbase Agentic Wallets (session/per-tx caps), **MetaMask Agent Wallet** (launched 8 Jun 2026 — default limits, allowlists, per-tx security check), Circle Agent Stack, AWS Bedrock AgentCore (built-in guardrails); startups **Fystack** (policy engine before the MPC signing layer, open-sourced), **Locus** (YC), Cobo, Chimoney. → Zawda's enforcement PoC lives here; **not a differentiator.**

**3. Blockchain-intelligence / compliance agents — INCUMBENT-OWNED.**
**TRM Labs** — TRM Agents (NL investigations, auto-tracing, workflow orchestration); now a **$1B unicorn**. **Elliptic** — AI Copilot (−50% alert review) + Data Fabric; **$120M Series D at $670M** (May 2026). **Chainalysis** — blockchain-intelligence agents (Links Mar 2026, summer rollout). → Zawda's triage agent competes head-on here; **can't win solo.**

**4. Agent identity / "Know Your Agent" + compliance-native FIs (adjacent).**
Skyfire (KYA, F5 partnership), Catena Labs (ACK-ID, $18M seed, "AI-native financial institution"), Nevermined (ID), Payman. KYC→KYA is an emerging regulatory theme.

**5. MENA crypto compliance — SERVICES, NOT PRODUCT (the gap).**
Antier (VARA-ready white-label exchange), Endida, AML Incubator, ACX, Defy — consultancies/white-label. **No MENA-native agentic compliance product exists.**

## Where Zawda sits
The only empty quadrant: **MENA-native agentic compliance** — FIU-specific SAR (CBB/VARA/ADGM), jurisdiction data, Arabic, and Gulf-regulator relationships. Validated by VARA's operational mandate (always-on monitoring, auto-SAR, auditable case management, instant FIU freeze).

## Implication
- Zawda's **moat is MENA localization + relationships + speed**, not the enforcement engine (commoditized) or the compliance agent (unicorns).
- The window is **closing** — the majors are entering the Gulf (Coinbase already Dubai/VARA). Move now.
